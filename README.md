# 🧩 Form Builder

A modern **dynamic form builder** built with **Next.js + TypeScript**, designed to create, manage, and render forms using a **schema-driven architecture**.

---

## 🚀 Features

- 🧠 Schema-based dynamic form rendering
- ⚡ Built with Next.js App Router
- 🧩 Reusable form components
- 🎯 Easy validation support
- 🔌 API-ready structure
- 📦 Scalable folder architecture
- 🎨 UI customizable (MUI / Tailwind ready)
- 🧱 Supports multiple field types
